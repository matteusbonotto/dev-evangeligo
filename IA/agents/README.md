# Agentes Especialistas

Cada agente é **especialista da área + especialista no projeto atual** (EvangeliGO — app gamificado de Teologia Cristã Reformada Calvinista).

## Agentes de domínio (específicos do projeto)

| Agente | Responsabilidade |
|--------|------------------|
| `teologia-reformada.md` | Autoridade doutrinária calvinista/reformada; valida conteúdo, trilhas, quizzes e referências bíblicas |
| `juridico.md` | Termos de Uso, LGPD, licenças de conteúdo (Bíblia Almeida, Harpa Cristã), conformidade legal |
| `privacidade.md` | Privacidade por design, minimização de dados, RLS, consentimento, exportação/exclusão |
| `gamificacao.md` | Sistemas de XP, níveis, sequências, conquistas, missões, recompensas e economia |
| `rpg.md` | Progressão de personagem, Armadura de Deus (Efésios 6), itens, inventário, atributos |
| `game-design.md` | Design de loops de jogo, onboarding estilo Duolingo, balanceamento, retenção e diversão |

## Agentes de engenharia

| Agente | Responsabilidade |
|--------|------------------|
| `project-manager.md` | Coordenação, roadmap, priorização, gate de conclusão |
| `software-architect.md` | Arquitetura, padrões, decisões técnicas |
| `frontend-specialist.md` | React, TypeScript, Vite, PWA, UI |
| `backend-specialist.md` | Supabase, funções, RLS, regras de domínio |
| `database-specialist.md` | Schema, migrations, índices, integridade |
| `qa-specialist.md` | Testes unitários, integração, E2E, regressão |
| `ux-ui-specialist.md` | Experiência, design system, acessibilidade visual |
| `security-specialist.md` | Segurança, RLS, secrets, OWASP |
| `accessibility-specialist.md` | Acessibilidade, VLibras, WCAG |
| `content-specialist.md` | Conteúdo bíblico, Harpa Cristã, devocionais, curadoria |

## Hierarquia de decisões

Em caso de conflito:

1. Requisito explícito do usuário
2. Segurança
3. Requisitos funcionais
4. Arquitetura
5. Padrões do projeto
6. Qualidade
7. Performance
8. Manutenção
9. Preferência individual do agente
