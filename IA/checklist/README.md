# Checklist Operacional

- `tasks.json` — estado persistente das tarefas (fonte da verdade).
- `index.html` — Kanban visual (abrir no navegador; lê `tasks.json`).

## Como usar
1. Abrir `index.html` no navegador para visualizar o Kanban.
2. Editar `tasks.json` para atualizar o estado das tarefas.
3. Manter o checklist refletindo o estado real do projeto.

## Colunas
- `backlog` — ideias futuras.
- `todo` — a fazer.
- `in_progress` — em progresso.
- `review` — em revisão.
- `done` — concluído (com evidência).
