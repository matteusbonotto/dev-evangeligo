# Memória do Projeto

## Visão geral
**EvangeliGO**: app gamificado estilo Duolingo de Teologia Cristã Reformada Calvinista. Reconstrução profissional a partir do legado funcional.

## Stack
- Frontend: React, TypeScript estrito, Vite, PWA.
- Estado remoto: TanStack Query.
- Backend: Supabase (PostgreSQL, RLS, funções).
- Testes: Vitest, Playwright, pgTAP.
- Formulários: React Hook Form + Zod.
