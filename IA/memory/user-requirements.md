# Requisitos do Usuário

## Solicitação original (2026-08-21)
O usuário pediu para executar o "prompt especialista em apps gamificados no estilo Duolingo", especializado em **Teologia Cristã Reformada Calvinista**, com **agentes especialistas** em: jurídico, privacidade, gamificação, RPG, game design, etc.

O projeto atual já existe (`dev-pwa-biblia-game`), mas o usuário quer **algo novo com tudo que funcionou, mas de forma profissional**, usando o `MASTER PROJECT BUILDER.md` como base.

## Requisitos derivados
1. **App gamificado estilo Duolingo** de Teologia Cristã Reformada Calvinista.
2. **Equipe de agentes especialistas**: teologia reformada, jurídico, privacidade, gamificação, RPG, game design, e demais.
3. **Nova versão profissional** que preserve tudo que funcionou no legado.
4. **Base no MASTER PROJECT BUILDER** (estrutura IA/, agentes, memória, docs, standards, commands, checklist).
5. **Idioma**: português (BR).

## Preferências implícitas
- Experiência serena, acolhedora e respeitosa (não manipulativa).
- Privacidade real (LGPD, dados religiosos como sensíveis).
- Conteúdo doutrinário reformado preciso.
- Gamificação a serviço do aprendizado, nunca mérito espiritual.
- Sempre consulte a pasta ia
- Antes de fazer alguma tarefa, verifique qual IA seka a mais adequada para a tarefa.
